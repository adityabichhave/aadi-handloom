# AADI Handloom — Luxury Maheshwari Handloom Website

A premium handcrafted web experience for AADI Handloom — a Maheshwari saree, suit, and dupatta house based in Maheshwar & Indore.

This project is built as a modern, performance-focused ecommerce-style showcase using Next.js and Tailwind CSS, with emphasis on luxury UI, cultural storytelling, and conversion design.

## 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/aadi-handloom.git
cd aadi-handloom
````

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
./node_modules/.bin/next dev
```

Open:

```
http://localhost:3000
```

---

## 🏗 Production Build

```bash
./node_modules/.bin/next build
./node_modules/.bin/next start
```
